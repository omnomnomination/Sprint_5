Список проведенных проверок:
1. Проверка успешного входа с валидными данными
2. Проверка сообщения об ошибке, если ввести слишком короткий пароль
3. Проверка входа по кнопке "Войти в аккаунт" на главной странице
4. Проверка входа через кнопку "Личный кабинет"
5. Проверка входа через кнопку в форме регистрации
6. Проверка входа через кнопку в форме восстановления пароля
7. Проверка перехода по клику на кнопку "Личный кабинет"
8. Проверка перехода из личного кабинета в конструктор
9. Проверка выхода из аккаунта по клику на кнопку "Выйти" в личном кабинете
10. Проверка перехода по клику на разделы "Булки", "Соусы" и "Начинки"

Запуск всех тестов командой python -m pytest -v tests/

Структура:
* tests - автотесты, разделенные по функциональности
* login_locators, registration_locators - описание элементов страниц (локаторы XPath)
* conftest.py - конфигурационный файл с фикстурой для запуска и закрытия браузера
* data.py - тестовые данные и функция генерации уникальных аккаунтов
* .gitignore - список исключений для Git
